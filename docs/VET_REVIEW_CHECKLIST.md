# 수의사 검수 체크리스트

- 연구 대상이 사람인지 동물인지 확인
- 대상 종, 품종, 표본 수와 연구 유형을 원문에서 확인
- 약물명·용량·단위·기간을 원문과 대조
- 상관관계와 인과관계를 구분
- 사례보고를 일반적인 치료 효과로 확대하지 않음
- 국내 허가·보험·진료 적용 여부를 추정하지 않음
- 응급 신호와 보호자 행동 지침이 과장되지 않았는지 확인
- 한글 번역이 원문의 의미와 불확실성을 보존하는지 확인
- 최신 문헌 확인이 필요한 부분을 표시
- 검수 후 수정하면 contentHash가 바뀌었는지 확인하고 재검수

검수 결과는 실제 사람의 ID, 역할, 시각, 체크리스트와 함께 Git 이력에 남긴다.
