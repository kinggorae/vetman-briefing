# 디자인 시안 작업 파일

`mockup.html` 은 그 자체로 완결된 단독 HTML 문서입니다.
(실제 2026-07-19 브리핑 6건 데이터 내장)

## 클로드에서 디자인 이어서 작업하기
1. claude.ai 새 대화를 연다
2. `mockup.html` 파일을 업로드(또는 내용을 붙여넣기)한다
3. "이 디자인을 이어서 다듬어줘 — ○○을 △△로" 처럼 요청한다
4. 마음에 드는 결과가 나오면 그 HTML을 받아 이 프로젝트에 반영 요청

## 구조 (파이프라인과 동일)
- `<style>` : 디자인 토큰(색·타입·여백) + 컴포넌트 스타일
- `<script id="issue">` : 데이터 배열 (JSON)
- `<script>` : 데이터를 카드로 렌더링하는 템플릿 함수

여기서 확정된 `<style>` 과 템플릿은 `src/build.js` 에 그대로 이식되어
매일 자동 발행되는 실제 사이트(vetman-briefing.pages.dev)에 반영됩니다.
브라우저에서 바로 열어보려면 파일을 더블클릭하면 됩니다.
